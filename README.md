# Portafolio web de Natalie Aliaga Vilugrón

Sitio personal responsivo que presenta mi perfil profesional, mi formación y mis proyectos.
Es un proyecto académico de desarrollo web de INACAP (sede Temuco), actualizado con mi situación actual.

## Sobre mí

- **Analista Programadora** (formación técnica finalizada) y estudiante de **Ingeniería en Informática**, INACAP Temuco.
- Trabajo en **Tierra Nube** en soporte técnico y desarrollo sobre **Odoo ERP** (Python, XML, PostgreSQL).

## Tecnologías

- HTML5
- CSS3
- [Bootstrap 5.1.3](https://getbootstrap.com/) (por CDN)
- [Font Awesome 5.9](https://fontawesome.com/) (íconos, por CDN)
- Google Fonts (Raleway)
- Git y GitHub para el control de versiones

## Estructura


## Cómo verlo localmente

1. Clona el repositorio: `git clone https://github.com/Natyvirtualgamer/fdsw-github.git`
2. Abre `index.html` en tu navegador. No requiere instalación ni servidor.

## Estado del proyecto

- Sitio estático de una sola página, responsivo, con navegación por secciones.
- El formulario de contacto es solo visual y todavía no envía mensajes. Para contactarme, usa LinkedIn o GitHub.
- Sin JavaScript propio; solo el de Bootstrap para el menú.
